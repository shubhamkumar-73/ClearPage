Font asset placeholders / licensing checklist

The CSS expects these optional local files:
- OpenDyslexic-Regular.woff2
- Lexend-Regular.woff2
- Lexend-SemiBold.woff2
- AtkinsonHyperlegible-Regular.woff2

They are not included in this source archive because network access was unavailable in the build environment, so the corresponding choices fall back to system sans-serif until you add the font binaries. Obtain them from their official project/repository, verify the license for the exact downloaded release (commonly SIL Open Font License for these families), and keep the license and attribution text here before redistributing. This project does not bundle or claim ownership of those font files.
